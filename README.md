
# 🎶 Dev Music Festival 2025

**Dev Music Festival 2025** é uma aplicação web desenvolvida com **Next.js** e **TypeScript**, celebrando a fusão entre música e tecnologia. A plataforma oferece uma experiência completa com cronograma do evento, compra de ingressos com geração de PDF, galeria de fotos, FAQ e tema claro/escuro, tudo isso com uma interface moderna, responsiva e acessível.

> ✅ ✅ Projeto 100% front-end. Deploy realizado com Vercel.

---

## ✨ Funcionalidades

- ✅ **Formulário de Compra de Ingressos**: Os usuários podem selecionar os ingressos, adicionar ao carrinho e finalizar a compra.
- ✅ **Geração de PDF**: Após a confirmação da compra, é gerado um PDF com o resumo da compra para ser enviado ao usuário.
- ✅ **Toast de Sucesso**: Ao completar a compra, o usuário vê uma mensagem de sucesso informando que a transação foi concluída com êxito.
- ✅ **Galeria de Fotos**: Uma seção para visualizar fotos dos artistas, palestrantes e do evento anterior, oferecendo uma visão completa do que esperar.
- ✅ **FAQ**: Seção com perguntas frequentes para ajudar os participantes a obter informações rápidas sobre o evento.

---

## 🛠️ Tecnologias utilizadas

- **React** com **TypeScript** e **Next.js**
- **TailwindCSS** para o design responsivo e estilização moderna
- **React Router** para navegação
- **React Hook Form** para o gerenciamento de formulários
- **Toastify** para exibição de mensagens de sucesso
- **jsPDF** para geração de PDF
- **Iconify** para ícones

## 🚀 Como rodar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/vicmariucha/teste-eventos
cd teste-eventos
```

### 2. Instale as dependências

```bash
npm install
npm run dev
```

Isso irá rodar o projeto localmente no seu navegador.
